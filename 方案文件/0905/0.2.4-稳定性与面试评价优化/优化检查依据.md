## 4. 未验证内容

- 真实模型 API 请求、实际 token 费用、追问质量和压缩质量。
- 真实 OCR 引擎和真实 VS Code 拖拽、停止、恢复、导出交互。
- 断电条件下的磁盘持久性、真实大文件性能和长期存储增长。
- 云端 CI runner、已发布 Release 和用户手中 VSIX 的具体内容。
- 旧存档是否已有不可恢复的数据损失；本次未读取用户实际面试历史来判断。

## 5. 规划中的关键取舍

1. 配对修复优先作用于共享历史边界，并对默认 native 回归，避免仅改 Pi。
2. 业务历史完整保存与模型请求预算分别处理，不承诺模型每次都收到全部历史。
3. 本地报告先明确来源与不确定性；独立模型语义评价在下一阶段评估，避免导出按钮隐式增加付费请求。
4. 新密钥使用官方 [SecretStorage](https://code.visualstudio.com/api/references/vscode-api#SecretStorage)；旧值处理保持可恢复，不在文档阶段执行迁移。
5. 修复性任务不需要引入新框架；扩展建议见主清单末尾，不自动进入实现范围。
