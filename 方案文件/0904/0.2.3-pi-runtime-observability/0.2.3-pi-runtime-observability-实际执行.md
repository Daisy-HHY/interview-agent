## 6. 最终决策

1. 时间线继续保持调试型最小内存视图。
2. 0.2.3 不引入 LLM summarizer；先积累同模型、同样本的真实 paired 数据。
3. trace 诊断记录保持 `keep-in-memory`，不默认持久化。
4. 动态预算策略已具备最小实现和测试，但默认关闭；真实命中率数据充分后再开启或调整阈值。

## 7. 未覆盖风险

- 没有真实模型 API Key，尚未完成真实摘要质量、实际 token 成本和真实延迟对照。
- 当前动态预算默认关闭，生产环境的最优阈值仍需要真实样本校准。
- 0.2.3 没有接入 trace 持久化，因此保留周期只等同于当前 Webview/进程生命周期。
- 云端 CI runner 结果仍需在 CI 平台执行后确认，本地测试已通过。
