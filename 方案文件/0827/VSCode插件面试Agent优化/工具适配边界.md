# 工具适配边界

0.1.12 不接入真实 MCP SDK，只收紧工具边界。

| 边界 | 可点击链接 | 约束 |
|---|---|---|
| 工具协议 | [base.py](../../../agent/tools/base.py) | 工具只需要提供 `name`、OpenAI function schema 和 `execute(**kwargs) -> str` |
| 原生 runtime | [agent_loop.py](../../../agent/agent_loop.py) | 只通过 `ToolRegistry` 查找和执行工具，不关心工具来源 |
| LangChain adapter | [langchain_tools.py](../../../agent/langchain_tools.py) | 只读取 `ToolRegistry.all_schemas()` 并调用 `registry.get(name).execute()` |
| 契约测试 | [test_langchain_runtime.py](../../../agent/tests/test_langchain_runtime.py) | fake MCP-like tool 不引入 MCP SDK，也能被 LangChain adapter 包装和执行 |

未来接入 MCP 时，只新增 MCP tool 到当前 `Tool` 协议的 adapter，然后注册进 `ToolRegistry`。不要把 MCP client/server 逻辑塞进 runtime 主循环。
