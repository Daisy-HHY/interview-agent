## 1. 本版本结论

0.1.12 已补齐 runtime 指标采集、诊断面板、Settings 自动刷新、工具边界约束、上传日志清理和 VSIX 打包。

本机未配置 `INTERVIEW_API_KEY`，因此没有执行真实 LangChain 在线 benchmark。按 0.1.12 闸门规则，默认 runtime 继续保留 `native`，不切到 `langchain`。

## 3. 真实 runtime 闸门

执行检查：

```powershell
if ($env:INTERVIEW_API_KEY) { .\.venv\Scripts\python.exe -m agent.runtime_benchmark --runtime both --rounds 5 --output runtime-benchmark-0.1.12.jsonl } else { Write-Output 'NO_INTERVIEW_API_KEY' }
```

结果：

```text
NO_INTERVIEW_API_KEY
```

结论：真实在线样本不足，未达到默认切换标准，`interview.agentRuntime.default` 继续保持 `native`。
